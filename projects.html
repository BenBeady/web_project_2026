Bill Leroy — Artist website

Overview

I worked directly with Bill Leroy of The Bannas to design and build his personal artist website. The project was a close collaboration from start to finish — Bill had a clear sense of his identity as a musician, and my job was to translate that into a web experience that feels as distinct as his music.

The site is currently in its final stages and will be launching soon. It's one of the projects I'm most proud of because it came from a real creative partnership, not just a brief and a wireframe.

What went into it

Beyond the visual design, the site is built on a fully semantic HTML5 structure with Flexbox layout, validated markup, and JSON-LD structured data implementing the MusicGroup and Person schemas. It's built to be fast, mobile-friendly, and accessible — so fans can reach it on any device, in any context.

Technologies used

  • Semantic HTML5 with proper landmark elements
  • CSS3 with Flexbox layout — no frameworks
  • JSON-LD structured data (MusicGroup, Person schemas)
  • Web accessibility — ARIA attributes, WCAG AA color contrast
  • JavaScript for interactive elements

Pi Kappa Alpha — University of Kentucky

The project

The official chapter website for Pi Kappa Alpha at the University of Kentucky. Built to serve a real organization with real needs: recruitment information, chapter history, member resources, and event coverage. The site needed to be fast, credible, and easy to navigate for prospective members who are evaluating whether to rush.

Why it matters

For a Greek organization, a website is often the first impression a prospective member gets. Weak structure, slow load times, or poor accessibility can end that impression before it starts. I treated this project with the same rigor I would apply to a commercial client — because for the chapter, it is that serious.

Structured data on the site helps the chapter appear in search results when students are looking for Greek life options at UK, which directly supports their recruitment goals.

This portfolio site

Built from scratch for this course

This site is the project you're reading right now. It was built to meet the requirements of a semester-long web development course while also functioning as a real professional portfolio. Everything here is hand-coded — no site builders, no CSS frameworks, no shortcuts.

The site uses semantic HTML5 throughout, Flexbox-only layout (no floats, no media-query-based grids), unique JSON-LD structured data on every page, and has been tested for accessibility using WAVE and reviewed with screen reader tooling.

Validation and testing

All HTML and CSS has been validated with the W3C Markup Validator and the W3C CSS Validator with zero errors. JSON-LD structured data has been validated with the Schema.org validator. Accessibility has been reviewed with WAVE and in high-contrast and screen-reader modes.

  • W3C HTML5 Validated — 0 errors across all pages
  • W3C CSS3 Validated — 0 errors
  • Schema.org JSON-LD Validated — all three pages
  • WAVE Accessibility Review — no contrast errors
